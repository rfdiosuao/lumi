## P0：交付前必须完成

### 真实机器启动测试

- [ ] 在另一台 Windows 机器上解压 portable zip。
- [ ] 双击 `OpenClaw.exe`，确认主窗口正常打开。
- [ ] 确认新版控制台 UI 正常显示，没有文字重叠、白屏、异常缩放。
- [ ] 点击启动核心服务，确认 Bridge 正常启动。
- [ ] 确认 OpenClaw 本地页面可打开。
- [ ] 记录测试机器系统版本、是否安装 WebView2、是否有杀毒拦截。

### 真实 U盘测试

- [ ] 把 portable 包复制到 U盘运行。
- [ ] 拔出 U盘后重新插入，再次运行。
- [ ] 换盘符后运行。
- [ ] 复制到另一块 U盘后运行，确认授权绑定行为符合预期。
- [ ] 断网状态下启动，确认提示可理解。
- [ ] U盘不可写或写入失败时，确认诊断页能提示问题。

### 授权全流程验收

- [ ] 未授权状态下启动，确认会进入授权页。
- [ ] 输入有效授权码，确认激活成功。
- [ ] 输入错误授权码，确认错误提示清楚。
- [ ] 授权过期时，确认提示清楚。
- [ ] 授权服务器不可达时，确认提示清楚。
- [ ] 授权成功后重启应用，确认授权状态仍然生效。

### 交付包清洁度

- [ ] 对最终 zip 跑 `verify-release.ps1`。
- [ ] 确认包内不含 `data/license.json`。
- [ ] 确认包内不含 `data/install_id.txt`。
- [ ] 确认包内不含 API Key、授权码、服务器密码、私钥。
- [ ] 确认 `data/brand_profile.json` 是目标客户 profile。
- [ ] 确认 `imgapi_config.json` 和 `video_config.json` 是空配置。

### 客户交付说明
